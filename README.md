# 魔法識字卡

離線可用嘅識字卡小程式（index.html 單一檔案）。

打開：https://sky3d20-jpg.github.io/magic-cards/

## 玩法
- **家長頁**（要先計一條數先入到）：用空格、逗號或者轉行分開，打要學嘅字或者詞語。
  - 打一個字＝一張單字卡。
  - 打 2–4 個字嘅詞語，預設「存成詞語卡」＝一張詞語卡（例如「蝴蝶」）。揀「拆成單字卡」就係舊做法：每個字一張卡，並用個詞做例子。
  - 想配圖可以喺後面加 emoji，例如「太空人👨‍🚀」。
  - 加入之前會先預覽。重複嘅字同非中文字會略去；超過 4 個字嘅詞語唔會加。
- **收服一張卡要過四關**，每關 1 粒星：
  1. 聽聲揀字
  2. 補完魔法詞語
  3. 捉星星
  4. 讀出嚟及配圖：先自己讀，撳「聽答案」對一對。如果張卡有圖，再「睇字揀圖」。
- **溫習**：收服咗嘅卡過 1、3、7 日會失去魔力，要喺今日任務入面溫習。溫習會隨機玩四關其中一關。
- **句子魔法**：今日嘅新卡全部收服之後，主頁會出「🪄 句子魔法」。今日收服嘅每張卡（有句子先算）各出一句：
  - 撳 🔊 聽成句（一開始會自動播一次），再按次序撳大字卡，砌返成句。詞語卡同多字詞會保持喺同一格，目標字會有少少粉紅色光。
  - 撳錯會彈返轉頭，唔扣星；可以再聽句子做提示。
  - 砌好之後同第 4 關一樣自己讀一次，撳「聽答案」，再揀「我讀啱」或者「再試一次」。每句 1 粒星。
  - 隨時可以撳 ✕ 離開，唔會罰；做咗嘅句子會記住。
  - 溫習有時會加 1–2 題句子題（只限有句子嘅卡），係額外練習，唔影響溫習日子。
  - 句子用書面語（小一課本風格）、繁體字。265 張內置卡每張都有 1–2 句內置句子（共 268 句，全部有 HiuMaan 錄音）。
- **家長改句子**：家長頁「全部字卡」表嘅「句子」欄，撳一下就可以幫任何一張卡（包括自己加嘅詞語卡）寫句子。用空格分開每一格，例如「我 想 吃 蘋果」；句子要包含張卡嘅字／詞語，會即刻預覽。家長句子會蓋過內置句子，用裝置朗讀；撳「用返內置句子」就還原。自己加嘅卡冇句子就唔會玩句子魔法。
- **進度備份**：家長頁「匯出／匯入進度」。舊版嘅備份代碼一樣用得；新備份代碼會包埋家長寫嘅句子。

## 聲音
- `audio/`：265 張內置卡嘅廣東話錄音，用 Microsoft zh-HK-HiuMaanNeural 預先生成。格式係 mp3、24kHz、單聲道、40kbps。
  - `c_<unicode>.mp3`：字，停一停，再讀詞語
  - `s_`：單字
  - `w_`：詞語
  - `p_XX`：固定句子（指示、稀有卡名）
  - `s2_<unicode>_<n>.mp3`：句子魔法嘅內置句子（manifest 入面嘅 `s`：句子 → 檔名）
- `audio/manifest.json` 列出所有檔案。app 會先播錄音；以下情況就改用裝置嘅廣東話朗讀（speechSynthesis）：
  - 搵唔到檔案
  - 用 file:// 打開
  - 家長自己加嘅字或者詞語，同家長自己寫嘅句子
  - 例外：如果家長加嘅詞語啱啱同內置詞語一樣，就用返嗰個錄音。
- 多音字已經按字典讀音修正，詳情見 POLYPHONE_REPORT。
