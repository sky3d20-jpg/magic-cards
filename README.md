# 魔法識字卡

離線可用嘅識字卡小程式（index.html 單一檔案）。

打開：https://sky3d20-jpg.github.io/magic-cards/

## 玩法
- **家長頁**（要先計一條數先入到）：用空格、逗號或者轉行分開，打要學嘅字或者詞語。
  - 打一個字＝一張單字卡。
  - 打 2–4 個字嘅詞語，預設「存成詞語卡」＝一張詞語卡（例如「蝴蝶」）。揀「拆成單字卡」就係舊做法：每個字一張卡，並用個詞做例子。
  - 想配圖可以喺後面加 emoji，例如「太空人👨‍🚀」。
  - 加入之前會先預覽。重複嘅字同非中文字會略去；超過 4 個字嘅詞語唔會加。
- **收服一張卡要過四關**，每關 1 粒星：
  1. 聽聲揀字
  2. 補完魔法詞語
  3. 捉星星
  4. 讀出嚟及配圖：先自己讀，撳「聽答案」對一對。如果張卡有圖，再「睇字揀圖」。
- **溫習**：收服咗嘅卡過 1、3、7 日會失去魔力，要喺今日任務入面溫習。溫習會隨機玩四關其中一關。
- **進度備份**：家長頁「匯出／匯入進度」。舊版嘅備份代碼一樣用得。

## 聲音
- `audio/`：265 張內置卡嘅廣東話錄音，用 Microsoft zh-HK-HiuMaanNeural 預先生成。格式係 mp3、24kHz、單聲道、40kbps。
  - `c_<unicode>.mp3`：字，停一停，再讀詞語
  - `s_`：單字
  - `w_`：詞語
  - `p_XX`：固定句子（指示、稀有卡名）
- `audio/manifest.json` 列出所有檔案。app 會先播錄音；以下情況就改用裝置嘅廣東話朗讀（speechSynthesis）：
  - 搵唔到檔案
  - 用 file:// 打開
  - 家長自己加嘅字或者詞語
  - 例外：如果家長加嘅詞語啱啱同內置詞語一樣，就用返嗰個錄音。
- 多音字已經按字典讀音修正，詳情見 POLYPHONE_REPORT。
